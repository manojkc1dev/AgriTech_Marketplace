# Ubiquitous Language Dictionary

| Term                        | Domain Context        | Definition                                                                                                              |
| :-------------------------- | :-------------------- | :---------------------------------------------------------------------------------------------------------------------- |
| **Producer**                | Producer Management   | An entity (Farmer or Cooperative) capable of harvesting and listing produce.                                            |
| **Produce Batch**           | Catalog & Inventory   | A specific, traceable harvest quantity defined by origin, harvest date, crop type, and initial weight.                  |
| **Quality Grade**           | Quality & Fulfillment | Classification assigned post-inspection (Grade A, Grade B, Rejected) dictating market eligibility.                      |
| **Listing**                 | Marketplace           | A public commercial offer by a Producer detailing available produce batch quantity and unit pricing.                    |
| **RFQ (Demand)**            | Marketplace           | Request for Quote submitted by a Buyer specifying required crop type, quantity, price target, and delivery window.      |
| **Negotiation Thread**      | Negotiation           | State-bound bargaining sequence containing binding offers and counter-offers between Buyer and Producer.                |
| **Fulfillment Allocation**  | Fulfillment           | The binding reservation of a specific Produce Batch or Cooperative Collection inventory to a confirmed Order line item. |
| **Pickup Task**             | Logistics             | Dispatch instruction for a Driver to collect a batch from a farm or collection center.                                  |
| **Proof of Delivery (PoD)** | Logistics             | Verified physical confirmation (signature/code) recorded by a Delivery Agent upon customer receipt.                     |
| **KYC Application**         | KYC & Compliance      | Document set and identity metadata submitted for compliance review prior to role authorization.                         |
